# LayoutPicker

LayoutPicker chooses one of the 13 layouts from a grid of thumbnails, with the hovered layout's name and description on one line below.

Provide `value`/`defaultValue`, `onChange`, `columns` (default 5) and `thumb` width.

- Thumbnails carry no labels, so nothing wraps; the info line truncates.
- Used inside the Layout submenu and in Settings.
