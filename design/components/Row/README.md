# Row

Row is one line of a settings Group: optional symbol, label, description, and a control on the right.

Provide `label`, optional `description`, `symbol` and the control as `control` or children. Wrap rows in `Group` (`title`, `footer`): an open list with hairlines between rows and no surrounding box. Labels and descriptions stay on one line and truncate.

- Labels are sentence case and name the effect ("Focus follows mouse").
- Put units and current values in the description, not the label.
